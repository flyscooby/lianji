# 练迹 · 训练记录

免费、简洁、专业的个人健身训练记录工具。

## 在线使用

https://flyscooby.github.io/lianji/

手机浏览器打开后可「添加到桌面」，像 App 一样全屏使用。

## 特性

- 力量训练记录（推/拉/腿模板，重量·次数·RPE·组间倒计时）
- 有氧训练记录（10 种类型，时长/距离/心率/感受）
- 身体数据追踪（体重 + 5 项围度 + 趋势图）
- 训练数据分析（周频率、周容量、单动作趋势、个人最佳）
- 训练日历（月视图、补录、休息日）
- JSON 备份恢复 / CSV 导出
- 深色浅色主题
- 完全离线可用，数据只存本机

## 隐私

所有训练数据保存在你的浏览器本地，不上传任何服务器。
本项目无后端、无账号、无追踪。

## 技术

原生 HTML/CSS/JS，零构建、零依赖。图表为手写 SVG。
